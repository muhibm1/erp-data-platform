## What happened

The first version of `int_customers` grouped partners by email with a window
function. Postgres puts every row with a null email in the same window, so
three unrelated Odoo partners with no email ("Public user" and two user
templates) became one customer. The `duplicate_customers` check flagged two
merges where one was expected, which is how it was caught.

## Decision

A missing email is never a match. Changes to the matching rule need finance
sign-off, because a wrong merge moves money between customers. Recorded as CON-102.

Found while building this project, before any finance table was used.
